# portfolio

## حاسبة المعدل العكسية

تُحسب علامة الاختبار اللازمة لكل مادة للوصول إلى المعدل المستهدف فيها باستخدام معادلة الحاسبة الحالية. إذا تجاوزت العلامة المطلوبة 20/20، تظهر المادة على أنها غير ممكنة بهذا الهدف.

## العد التنازلي للمواعيد الدراسية

يمكن إضافة مواعيد الاختبارات والواجبات مع التاريخ والوقت، وتعرض الأداة الوقت المتبقي وتتيح حذف المواعيد. تُحفظ البيانات محليًا في المتصفح المستخدم، ولا تتم مزامنتها بين الأجهزة.

## امتحانات شهادة التعليم المتوسط

توجد ملفات امتحانات BEM بصيغة PDF في `exams/bem/`، مرتبة حسب المادة وتغطي السنوات 2022–2026. روابط التنزيل في `index.html` تشير إلى هذه الملفات محليًا؛ عند نشر الموقع، أرفق مجلد `exams` كاملًا مع ملفات الموقع.

## التعليقات

يستخدم قسم التعليقات Giscus المربوط بمستودع GitHub. يجب أن يكون المستودع عامًا، مع تفعيل **Discussions** وتثبيت تطبيق Giscus؛ تظهر التعليقات عند فتح الموقع المنشور عبر HTTPS. التعليقات القديمة المحفوظة محليًا لا تُنقل تلقائيًا إلى Giscus.
